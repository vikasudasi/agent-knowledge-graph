# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-01

### Added

- Initial CLI surface for `init`, `build`, `query`, `status`, `visualize`, `watch`, and `llm` command groups.
- Pipeline framework with `session-ingest` reference implementation.
- Adapter modules for Hermes, MCP, and optional LangChain integration.
- Documentation set: architecture, pipelines, adapter usage, and contribution guide.
- Expanded CLI and adapter tests targeting previously low-coverage modules.
