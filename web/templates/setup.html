MCP client setup

Connect your agent using the HTTP MCP endpoint and your API key.

Replace {{ placeholder_key }} with your actual key if you haven't already.

Hermes (~/.hermes/config.yaml)

mcp_servers:
  knowledge-graph:
    url: "{{ mcp_url }}"
    transport: streamable-http
    headers:
      Authorization: "Bearer {{ placeholder_key }}"

Available tools

  • kg_query — natural-language question → Cypher → results
  • kg_semantic_search — vector semantic search
  • kg_traverse — graph traversal from a node
  • kg_stats — node/relationship counts and index status

SSE fallback endpoint: {{ mcp_url }}/sse/sse (POST messages to {{ mcp_url }}/sse/messages/)
